# Pulse — Repo Health Score для SourceCraft

Pulse — веб-сервис, который анализирует открытые репозитории SourceCraft и вычисляет для
каждого Repo Health Score от 0 до 100. Сервис показывает детализацию по шести категориям и
факты, на которых основан каждый вывод. Для каждого репозитория он формирует
приоритизированные рекомендации с ожидаемым влиянием на оценку. Опубликованные оценки
образуют рейтинг здоровья открытых репозиториев. Пользователь, вошедший через Яндекс ID,
может проанализировать собственный репозиторий, в том числе приватный.

## Методика кратко

```
C_k   = Σ w_i · m_i / Σ w_i                 по метрикам категории k с данными
S₀    = Σ W_k · C_k / Σ W_k                 по категориям с данными
Score = round(clamp(S₀ − штрафы, 0, 100))
```

| Категория | Вес | Основные метрики |
|---|---:|---|
| Безопасность | 20 % | открытые находки SourceCraft AppSec: critical, high, medium, секреты |
| Код | 20 % | тесты, длина файлов, комментарии, TODO/FIXME, линтер, lock-файл, автообновление зависимостей; ИИ-ревью выборки кода |
| Активность | 15 % | коммиты (без пустых) и авторы за 90 дней, свежесть, bus factor, релизы, pull request |
| Документация | 15 % | README, LICENSE, примеры, CONTRIBUTING, CHANGELOG, docs/; рубрика README от модели |
| CI/CD | 15 % | наличие пайплайна, запуск тестов и линтера, проверка pull request, успешность прогонов |
| Задачи | 15 % | доля закрытых, доля зависших, время до начала работы |

Штрафы: −15 за открытый секрет и −10 за открытую critical-уязвимость по данным AppSec,
−8 за отсутствие LICENSE.

## Пользовательские сценарии

**Просмотр открытого репозитория.** `/rating` → фильтр по языку и сортировка → карточка
репозитория `/r/<org>/<repo>` (балл, категории, история оценок) → «Подробности анализа»
`/a/<id>` → «Скачать» (Markdown или PDF). С карточки — «Сравнить» с другими репозиториями.

**Анализ собственного репозитория.** Вход через Яндекс ID → «Мои репозитории» → личный токен
SourceCraft → список репозиториев, где у пользователя роль admin или maintainer → «Оценить» →
страница анализа с фазами выполнения → отчёт и рекомендации → после исправлений
«Оценить заново».

## Быстрый старт

```bash
git clone https://git.sourcecraft.dev/lct-hackaton-2026/case-18-repo-health-score-team-59.git pulse
cd pulse
pnpm install
cp .env.example .env     # DATABASE_URL, AUTH_SECRET, SOURCECRAFT_PAT, при необходимости AI_*
pnpm db:migrate
pnpm dev                 # http://localhost:3000
```

Проверка без базы данных:

```bash
pnpm test                          # контрольные сценарии методики
pnpm collect <org> <repo> --score  # расчёт оценки репозитория в консоли
```

Развёртывание на Vercel и в Docker, расписание и переменные окружения —
в [deployment.md](docs/deployment.md).

## Технологии

Next.js 15, React 19, TypeScript, Tailwind CSS, PostgreSQL (Neon), Drizzle ORM, Zod,
isomorphic-git, Auth.js v5, Vitest. Хостинг — Vercel с Fluid compute или Docker Compose.
