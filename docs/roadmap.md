# План развития до финальной версии

## 1. Текущее состояние (промежуточная сдача)

Реализована обязательная часть ТЗ:

- оценка по шести категориям с формулой, нормализацией и обработкой отсутствующих данных;
- Repo Health Score с детализацией до метрик и фактов, сильными и слабыми сторонами,
  покрытием данных;
- приоритизированные рекомендации с ожидаемым приростом балла;
- рейтинг открытых репозиториев: лайки, язык, последняя активность, фильтр и три сортировки;
  каталог — весь `GET /repos`;
- вход через Яндекс ID, анализ собственных и приватных репозиториев по правам владельца;
- периодический анализ: проверка новых коммитов в 00:00 и 12:00 МСК, переоценка
  изменившихся, история оценок;
- выгрузка отчёта в Markdown, PDF и PNG; отчёты по всем репозиториям рейтинга лежат в
  [reports/](reports/README.md), в админке — выгрузка всех отчётов ZIP-архивом;
- исходный код — в SourceCraft: `lct-hackaton-2026/case-18-repo-health-score-team-59`;
  GitHub остаётся публичным зеркалом, из которого собирается Docker-образ;
- сравнение до четырёх репозиториев, аналитика ревью pull request, CODEOWNERS, исключение
  пустых коммитов из метрик активности.

## 2. Задачи до финальной сдачи

### Обязательные материалы сдачи

| № | Задача | Результат |
|---:|---|---|
| 1 | Установка из SourceCraft | ссылки `deploy/setup.sh` и сборка Docker-образа в SourceCraft CI вместо GitHub-зеркала |
| 2 | Крупные репозитории в отчётах | отчёты по репозиториям от 10 000 файлов или 20 000 коммитов в [reports/](reports/README.md) с временем анализа |
| 3 | Видео демонстрации | рейтинг, страница анализа, отсутствующие данные, рекомендации, вход и анализ своего репозитория, выгрузка, первичный и повторный запуск, расписание |
| 4 | Презентация | проблема, аудитория, методика, архитектура, пользовательский путь, ограничения, развитие |

### Улучшение методики и аналитики

| № | Задача | Цель |
|---:|---|---|
| 5 | Контрольные сценарии на реальных репозиториях | таблица «проблема → изменение балла» для каждой категории на репозиториях SourceCraft в дополнение к автотестам |
| 6 | Время до первого ответа по задаче | комментарии к задачам выборочно, в пределах лимита API |
| 7 | Возраст TODO/FIXME | дата появления пометки по истории для небольших репозиториев с полной историей |

### Функции со звёздочкой

| № | Задача | Направление |
|---:|---|---|
| 8 | Фильтры рейтинга по наличию CI и размеру | рейтинг и сравнение |
| 9 | Динамика позиции в рейтинге | рейтинг и сравнение |

## 3. Развитие после хакатона

- Обработка событий SourceCraft вместо опроса по расписанию: переоценка сразу после push.
- Выделенные воркеры для крупных репозиториев без ограничения 300 с.
- Отраслевые профили весов: библиотека, сервис, учебный проект.
- Командные отчёты: сводка по всем репозиториям организации.
