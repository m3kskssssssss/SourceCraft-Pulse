# Публичный API и выгрузки

API не требует ключа. Ответы — JSON в UTF-8, если не указано иное. При превышении лимита
частоты возвращается `429` с заголовком `Retry-After`. Описание с примерами также доступно
на странице `/api-docs` стенда.

## 1. Эндпоинты

| Метод и путь | Ответ | Лимит с одного адреса |
|---|---|---|
| `GET /api/public/leaderboard` | рейтинг опубликованных оценок | 60 в минуту |
| `GET /api/public/repos/{org}/{repo}` | последняя опубликованная оценка репозитория | 60 в минуту |
| `GET /api/public/repos/{org}/{repo}/report` | полный отчёт: категории, метрики, штрафы, рекомендации, поле `extras` (CODEOWNERS, пустые коммиты, ревью PR); `?format=md` — Markdown | 60 в минуту |
| `POST /api/public/analyze` | оценка публичного репозитория в запросе | 20 запросов в минуту, 5 новых анализов в час |
| `GET /api/badge/{org}/{repo}.svg` | SVG-бейдж с баллом | 120 в минуту |
| `GET /api/card/{org}/{repo}.svg` | SVG-карточка: балл, категории, язык, дата пересчёта | 120 в минуту |
| `GET /api/health` | состояние приложения и базы | — |

### Параметры рейтинга

`GET /api/public/leaderboard?sort=score&lang=Go,Python&q=ui&limit=20&offset=0`

| Параметр | Значения |
|---|---|
| `sort` | `score` (по умолчанию), `likes`, `activity`, `forks` |
| `lang` | языки через запятую |
| `q` | подстрока в имени репозитория |
| `limit` | 1–100 |
| `offset` | смещение от начала |

### Оценка из командной строки

```bash
curl -X POST https://source-craft-pulse.vercel.app/api/public/analyze \
  -H 'content-type: application/json' \
  -d '{"repo":"org/repo"}'
```

- Если есть отчёт моложе 12 часов, он возвращается без нового анализа.
- Если репозиторий уже анализируется, возвращается `202` и адрес для опроса статуса.
- Иначе анализ выполняется в запросе (обычно 30–60 с), и возвращается готовый отчёт.
- Оценка публичного репозитория по публичным данным публикуется в рейтинге.

Коды ошибок: `400` — неверный формат `org/repo`; `403` — репозиторий не публичный;
`404` — репозиторий не найден; `429` — превышен лимит; `502` — SourceCraft недоступен.

## 2. Выгрузка отчёта

Права доступа совпадают с правами на страницу анализа: опубликованный анализ доступен всем,
неопубликованный — только его автору.

| Путь | Формат | Содержание |
|---|---|---|
| `/a/{id}/report.md` | Markdown | итог, покрытие, категории с метриками и фактами, сильные и слабые стороны, штрафы, рекомендации с приоритетом, дополнительная аналитика, пробелы данных, дата анализа |
| `/a/{id}/export/report.pdf` | PDF (A4) | подробный отчёт |
| `/a/{id}/export/report.png` | PNG | подробный отчёт изображением |
| `/a/{id}/export/card.pdf`, `/a/{id}/export/card.png` | PDF, PNG | карточка: балл и категории |

Кнопки выгрузки находятся в шапке страницы анализа и на карточке репозитория.

## 3. Сравнение

`/compare?r=org/repo&r=org/repo` — страница сравнения до четырёх репозиториев с опубликованной
оценкой. Состав сравнения хранится в адресе, ссылку можно передать.

## 4. Бейдж для README

```markdown
[![Pulse](https://source-craft-pulse.vercel.app/api/badge/<org>/<repo>.svg)](https://source-craft-pulse.vercel.app/r/<org>/<repo>)
```

Бейдж отдаётся без кэша и сразу отражает новую оценку. Приватные репозитории бейджа не
имеют. Параметр `?debug=1` возвращает причину, если бейдж пустой.
