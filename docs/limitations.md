# Ограничения решения

| Область | Ограничение | Причина | Как отражается в оценке |
|---|---|---|---|
| Безопасность публичных репозиториев | в публичной оценке категория «Безопасность» имеет статус «нет данных» | AppSec отдаёт результаты только участникам репозитория | категория исключена из балла у всех репозиториев рейтинга одинаково; владелец видит оценку с AppSec в личном блоке |
| AppSec приватных репозиториев | данные есть только при подключённом у владельца модуле безопасности SourceCraft | без него AppSec не сканирует приватные репозитории | категория «нет данных» |
| Прогоны CI | доля успешных прогонов не входит в публичную оценку | прогоны доступны только участникам | CI/CD в публичной оценке считается по конфигурации пайплайна |
| Длительность пайплайнов и динамика CI | не учитываются | в публичной оценке прогоны недоступны | — |
| Время до первого ответа по задаче | не считается; вместо него — время до начала работы или закрытия | комментарии к задаче требуют отдельного запроса на каждую задачу при лимите API 10 запросов в секунду | метрика `issues.reaction_time` |
| Выборки API | последние 50 задач и 50 pull request | время анализа и лимит API | доли считаются по выборке |
| Возраст TODO/FIXME | не определяется | клон ограничен окном 90 дней, `blame` по нему был бы неверным | учитывается плотность пометок на 1000 строк |
| CODEOWNERS | показывается в отчёте, в балл не входит | признак процесса, а не качества документации; не должен сдвигать места в рейтинге | раздел «Дополнительная аналитика» |
| Крупные репозитории | читается выборка: до 1500 файлов, история до 2000 коммитов за 90 дней; от 5000 записей в дереве — только последний снимок без истории | ограничение функции 300 с | неполные фазы отмечаются в блоке «Что не удалось собрать»; метрики без данных исключаются |
| ИИ-оценки | категории «Код» и «Документация» при успешном ответе модели определяются ею | модель оценивает содержание, а не наличие файлов | ответы проверяются схемой и кэшируются; при сбое — детерминированные метрики |
| Приватный код и модель | ИИ-ревью и рубрика README для приватных репозиториев не выполняются | код приватных репозиториев не передаётся во внешние сервисы | категории считаются по детерминированным метрикам |
| Источник данных | используется REST API SourceCraft и git, CLI SourceCraft не используется | CLI рассчитан на интерактивный вход; для веб-сервиса подходит персональный токен | — |
| Пустые коммиты в ранее выполненных анализах | не определяются | в фактах старых анализов не сохранены деревья коммитов | «нет данных» до следующей оценки; метрика коммитов считается по всем коммитам |
| Ревью pull request | анализируются последние 20 PR; у приватных репозиториев, оценённых ранее, — «нет данных» | запрос на каждый PR при лимите API; догрузка для старых анализов идёт сервисным токеном, у которого нет доступа к приватным | раздел «Дополнительная аналитика», в балл не входит |
| Охват каталога | все публичные репозитории загружаются в каталог; оценка каталога запускается администратором и ограничена бюджетом на модель | полный анализ требует клона и вызовов модели | рейтинг показывает, сколько репозиториев каталога оценено |
