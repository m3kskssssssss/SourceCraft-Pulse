Что сделать: Поставьте тег версии (например, v1.0.0) и опубликуйте релиз с описанием изменений — и заведите CHANGELOG.

**2. Добавьте .editorconfig.** Почему важно: Код без тестов, линтера и зафиксированных зависимостей дорого менять: ошибки находят пользователи, а не проверки. Сейчас: .editorconfig отсутствует. Что сделать: Положите .editorconfig в корень: кодировка utf-8, перевод строки lf, отступы как в проекте.

**3. Проводите изменения через pull request.** Почему важно: По активности решают, живой ли проект: заброшенную зависимость никто не обновит, когда в ней найдут ошибку. Сейчас: Pull request не используются. Что сделать: Вносите изменения через pull request даже в одиночку: история решений и место для проверок CI.

**4. Включите автообновление зависимостей.** Почему важно: Код без тестов, линтера и зафиксированных зависимостей дорого менять: ошибки находят пользователи, а не проверки. Сейчас: Автообновления зависимостей нет. Что сделать: Включите автообновление зависимостей (Renovate или Dependabot, если он доступен), чтобы исправления уязвимостей приходили сами pull request.
