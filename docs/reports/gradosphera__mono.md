**2. Проводите изменения через pull request.** Почему важно: По активности решают, живой ли проект: заброшенную зависимость никто не обновит, когда в ней найдут ошибку. Сейчас: Pull request не используются. Что сделать: Вносите изменения через pull request даже в одиночку: история решений и место для проверок CI.

**3. Включите автообновление зависимостей.** Почему важно: Код без тестов, линтера и зафиксированных зависимостей дорого менять: ошибки находят пользователи, а не проверки.
